# API Data Collector

A Python project designed to retrieve data from public REST APIs using HTTP requests.

## Project Overview

The API Data Collector retrieves structured information from a public API and prepares it for further data processing and storage.

## V1.1 — Initial API Request

The first version establishes a connection with the JSONPlaceholder REST API.

**Features:**
- HTTP GET requests using Requests.
- API response retrieval.
- HTTP status code inspection.
- JSON response parsing.
- Basic data inspection.

## Technologies

- Python
- Requests
- REST API
- JSON

## API Source

[JSONPlaceholder](https://jsonplaceholder.typicode.com/)

## Installation

Clone the repository:

```bash
git clone https://github.com/Leandro-AIdev/API-Data-Collector.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python src/main.py
```
